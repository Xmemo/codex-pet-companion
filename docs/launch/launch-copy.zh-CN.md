统一定位：

> Pet Pomodoro 是一个面向 macOS Codex 用户、受 Huberman Lab 超昼夜节律讨论启发的番茄钟。它提供 25/50/90 分钟专注选项，并在休息时让原有电子宠物放大，以安静的待机状态形成可见的“暂停”。周期数据保存在本地，可由用户自主交给 AI 分析。

所有渠道都必须保留的边界：

- 独立、非官方社区项目。
- 仅支持 macOS；从源码安装，需要 Xcode Command Line Tools。
- 不打包 Codex 内置宠物资产，不使用 OpenAI Logo。
- 无遥测、无云同步、不自动调用 AI，不承诺医疗或生产力效果。
- `90/20` 是受到超昼夜节律科普启发的可选产品预设，不是适用于所有人的生理处方。

源码首发不以 GIF 或截图为门槛。后续演示可使用 Codex 默认宠物的真实运行画面，但不得提交或打包提取后的内置素材。
