# V2EX 首发稿

## 标题

分享一个让 Codex 电子宠物参与专注与休息节奏的 macOS 开源工具

## 正文

我最近做了一个小工具：**Pet Pomodoro for Codex**。

它首先是一个受 Huberman Lab 超昼夜节律讨论启发的番茄钟：把有边界的专注和有意识的恢复做成可选节奏，再把 Codex 原有的电子宠物接进这个闭环。宠物在休息时放大、平静待机，产生明显的视觉“暂停”感，而不是只弹出一条通知。

- 点击透明番茄面板，选择 25、50 或 90 分钟；
- 工作阶段保留紧凑倒计时；
- 到休息阶段，当前选择的宠物会放大成为全屏视觉提示；
- 每轮目标、时间事件和完成状态保存在本地 SQLite，可导出 JSON，再由用户自主交给 AI 分析。

### 为什么做 25/50/90？

产品受到超昼夜节律、持续注意和工作间歇研究的启发，也参考了 Huberman Lab 关于 90 分钟以内专注段与主动放松的公开科普。

但我不想用“科学”包装一个过度确定的结论。现有研究更可靠地支持的是：适当休息有助于减轻疲劳，并可能在部分任务中帮助注意或表现。对“清醒认知普遍存在精确 90 分钟周期”的直接证据并不一致。所以 25/50/90 都只是可以自行比较的产品预设，不是生理处方。仓库里会同时列出支持证据和反面研究。

### 本地优先

- 无遥测、无广告、无云同步；
- 不启动网络服务，也不会自动调用 AI；
- 历史记录位于 `~/.codex/ultradian-rhythm/sessions.sqlite`；
- 可运行 `ultradian history --limit 50 --json` 导出；
- 数据里可能包含项目目标与 Review，分享给任何模型前应先自行检查。

### 安装边界

目前只支持 macOS。Release 不提供未签名二进制，而是从源码安装，本地使用 Xcode Command Line Tools 编译 Swift renderer，并通过 LaunchAgent 运行。

这是独立、非官方社区项目，与 OpenAI 没有隶属或背书关系。仓库和 Release 不包含 OpenAI Logo、提取后的 Codex 内置宠物图集或其他专有资产。

GitHub：https://github.com/Xmemo/codex-pet-companion

我尤其想了解三类反馈：安装是否顺畅、哪些默认/自定义宠物兼容、全屏休息提示是否真的能让人离开当前任务。
