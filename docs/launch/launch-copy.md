Shared positioning:

> Pet Pomodoro is a science-informed Pomodoro timer for Codex on macOS. Inspired by Huberman Lab's ultradian-rhythm framing, it offers 25/50/90-minute focus choices and turns the existing Codex pet into a calm visual pause cue when recovery begins. Session data stays local for user-directed AI analysis.

Required boundaries in every channel:

- Independent, unofficial community project.
- macOS only; installs from source and requires Xcode Command Line Tools.
- No bundled Codex pet assets or OpenAI logos.
- No telemetry, cloud sync, automatic AI calls, or medical/productivity guarantees.
- `90/20` is an optional product preset inspired by ultradian-rhythm science communication, not a universal biological prescription.

Visual assets are optional for the source launch. If a demo is added later, use a real default Codex pet, but never commit or package extracted built-in assets.
