# Ultradian Pixel Cat

An original Codex pet pack featuring a white pixel cat with a tomato-shaped rhythm badge.

## Files

- `spritesheet.webp`: the original pet sprite atlas.
- `pet.json`: Codex pet metadata.
- `companion.json`: optional companion animation configuration.

## Use

Copy this directory into `~/.codex/pets/ultradian-pixel-cat/` to use it as a custom pet. The companion configuration selects a restrained idle/rest sequence from the sprite atlas.
